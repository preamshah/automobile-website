# Autofix - Auto Maintenance & Repair Service

A responsive auto maintenance and vehicle repair website built with **HTML5, CSS3, and JavaScript**.

The project contains a modern automotive service landing page with sections for services, company information, recent work, contact details, and responsive navigation.

## Features

- Responsive navigation menu
- Modern automotive service landing page
- Hero section with animated vehicle image
- Vehicle repair and maintenance service cards
- About section with business statistics
- Recent projects / work showcase
- Contact information and opening hours
- Social media links
- Google Fonts integration
- Material Symbols icons
- Custom animations and responsive styling
- Lightweight frontend with no framework dependency

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Google Material Symbols

## Getting Started

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Open the project

```bash
cd autofix-project
```

### 3. Run locally

Because this is a static frontend project, you can open `index.html` directly in your browser.

For a better development workflow, you can also use the **Live Server** extension in Visual Studio Code.

## VS Code Live Server

1. Open the project folder in Visual Studio Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

## Deployment

This project can be deployed on static hosting platforms such as:

- GitHub Pages
- Netlify
- Vercel
- Hostinger
- Cloudflare Pages

Make sure the project root contains `index.html`.

## Customization

You can customize the website by editing:

```text
assets/css/style.css
```

for design and responsive styling, and:

```text
assets/js/script.js
```

for interactive functionality.

Replace images inside:

```text
assets/images/
```

while keeping filenames consistent, or update the corresponding image paths in the HTML.
